# Royal Crystal Cleaning

Static Astro and Tailwind CSS marketing website for Royal Crystal Cleaning.

## Commands

```bash
npm run dev
npm run check
npm run build
npm run preview
```

## Notes

- Static site only: no backend, database, CMS, booking system, payments, portal, or dashboard.
- SEO includes canonical URLs, Open Graph tags, Twitter cards, LocalBusiness JSON-LD, robots.txt, and generated sitemap files.
- Realistic WebP marketing images live in `public/images` and can be replaced later using the same filenames.
